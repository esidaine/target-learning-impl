## Overview & Scientific Scope

Standard feedforward networks rely on global backpropagation of error gradients. This project implements an alternative bio-inspired training regime combining three core concepts:

1. **Target Learning:** Top-down feedback drives hidden neurons toward target activity states; local updates minimize the delta between controlled and baseline activations.
2. **Dynamical Feedback Control (DFC):** A dynamical controller projects output errors through feedback matrices $Q_i$ to steer layer populations during a settling phase.
3. **Dendritic Modulation:** Evaluates how bottom-up feedforward signals and top-down control signals integrate via **additive** or **multiplicative** gain modulation.

> **Scope Note:** This repository is an independent research framework inspired by Target Learning (Aceituno et al.) and Deep Feedback Control (Meulemans et al.), rather than an exact reproduction of either paper.

## Mathematical Formulation

Each training minibatch ($B$) progresses through three sequential phases for population $i$ with forward weights $W_i$ and feedback weights $Q_i$:

### 1. Baseline Phase

Feedforward propagation without top-down intervention:
$$a_i^{\mathrm{base}} = f_i\left(W_i a_{i-1}^{\mathrm{base}}\right)$$

### 2. Control Phase

An output control signal $u$ generated by a proportional-integral (PI) controller projects to local population inputs:
$$c_i = Q_i u$$

Dendritic integration modes govern the resulting target activation $a_i^{\mathrm{ctrl}}$:

- **Additive Mode:**
  $$a_i^{\mathrm{ctrl}} = \text{LeakyReLU}\left(z_i + \tanh(c_i)\right)$$
- **Multiplicative Mode (Gain Control):**
  $$a_i^{\mathrm{ctrl}} = \left(1 + \tanh(c_i)\right) \cdot \text{ReLU}(z_i)$$

### 3. Local Plasticity Phase

Synaptic weights updates reflect local activity differences between controlled and baseline states:
$$\Delta W_i = \frac{\eta_w}{B} \sum_{b=1}^{B} \left(a_{i,b}^{\mathrm{ctrl}} - a_{i,b}^{\mathrm{base}}\right) \left(a_{i-1,b}^{\mathrm{pre}}\right)^T$$

python -m venv .venv

## Execution & Reproducibility

### 1. Single-Configuration Training

First, check config.py and define the desired parameters. Also verify, the parameters selected in main in train.py
Then, run a default single-seed MNIST or XOR training run with:

```bash
python src/train.py
```

### 2. Matched MNIST Benchmarking

Run evaluation across multiple seeds to compare additive vs. multiplicative dendritic integration. This may take a while:

```bash
python src/mnist_evaluation.py --epochs 100 --seeds 7 42
```

### 3. XOR Mechanism & Ablation Experiments

To see the results for the XOR task, run the following:

```bash
# Mechanism diagnostics across seeds
python src/xor_proof_of_mechanism.py --epochs 750 --dendritic-effect multiplicative

# Ablation experiment (Full Method vs. No Control vs. Controller Only)
python src/ablations.py --epochs 750
```

## Handoff Notes & Known Limitations

- **Target Formulation:** Top-down targets use direct dataset class targets during control rather than the nudged output formulations found in canonical DFC.
- **Feedback Matrix Updates:** Feedback matrices $Q_i$ are initialized from transpose forward weights $W_i^T$ and refreshed regularly.
- **Control Formulation:** The controller can operate in backpropagation and PI mode. The configuration parameter `use_derivative` modulates feedback via pre-activation derivatives rather than a true PID derivative term.
- **Multiplicative Controllability:** In multiplicative mode, dead units ($\text{ReLU}(z_i) \le 0$) yield zero local derivative, which can induce inactive dead-zone dynamics.
- **Logging:** Weights & Biases integration and model checkpointing are supported in `utils/utils.py` but disabled by default in entry scripts.
